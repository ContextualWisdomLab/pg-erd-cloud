💡 What:
Changes the '접근 관리' (Access Management) button in the ExportModal to use `aria-disabled="true"` instead of the native HTML `disabled` attribute, and manually prevents default click actions. Also updates the relevant tests.

🎯 Why:
The native HTML `disabled` attribute removes interactive elements from the browser's tab order. Because this button provides critical access-control guidance via an `aria-describedby` hint, screen reader and keyboard users were previously unable to focus on it to discover why it was disabled or read the context.

📸 Before/After:
No visual changes. (Maintained visual styling of `opacity: 0.6` and `cursor: not-allowed`).

♿ Accessibility:
- Keeps the disabled control in the tab order.
- Allows screen readers to announce the disabled state AND the `aria-describedby` helper text ("접근 권한 관리는 프로젝트 권한 설정에서 처리합니다.").
