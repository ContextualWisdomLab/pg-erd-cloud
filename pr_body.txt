💡 What: Replaced the native `disabled` attribute with `aria-disabled="true"` on the ExportModal's "접근 관리" (Access Management) button, manually blocking clicks and ensuring CSS styles still apply.
🎯 Why: Native `disabled` attributes remove elements from the document's tab order, making it impossible for keyboard and screen reader users to focus the button and discover the helpful `aria-describedby` hint explaining *why* it's disabled.
📸 Before/After: Visuals remain identical (the button remains grayed out with a not-allowed cursor), but the element is now focusable.
♿ Accessibility: The button is now reachable via keyboard navigation (Tab key), allowing screen readers to announce both its disabled state and the linked hint explaining that access control is managed in project settings.
