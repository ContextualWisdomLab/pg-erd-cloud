# Architecture Decision Records

ADRs record decisions that affect product boundaries, deployment profiles,
security controls, data contracts, or release claims. They are historical
records: when a decision changes, add a superseding ADR instead of rewriting an
accepted one.

## Index

| ADR | Decision | Status |
| --- | --- | --- |
| [0002](0002-product-technical-gap-baseline.md) | Product and technical gap baseline | Proposed |

## Status values

- **Proposed:** under review; implementation must not claim the decision is final.
- **Accepted:** approved decision is the current authority.
- **Superseded:** replaced by a later ADR.
- **Deprecated:** no longer applicable.
- **Rejected:** considered and explicitly not adopted.
