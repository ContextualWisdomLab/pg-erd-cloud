⚡ Bolt: [성능 개선] 검색 가능한 텍스트의 WeakMap 캐싱 추가

💡 What: 검색 가능한 필드를 소문자로 변환 및 연결한 단일 문자열을 `WeakMap`에 캐싱하여 노드 검색 시 재사용하도록 변경했습니다.
🎯 Why: 기존에는 React Flow에서 노드를 이동할 때 발생하는 60fps 프레임 렌더링마다 모든 노드의 필드에 대해 `.toLocaleLowerCase()`가 반복 호출되어 대량의 문자열 객체가 생성되고 심각한 가비지 컬렉션 부하를 일으켰습니다.
📊 Impact: 검색 중 노드 이동 시 발생하는 불필요한 문자열 메모리 할당을 제거하여 프레임 드롭을 방지하고 에디터 성능을 향상시켰습니다.
🔬 Measurement: 검색어를 입력한 상태에서 다이어그램 노드를 드래그할 때 브라우저 프로파일러를 통해 줄어든 메모리 할당 및 GC 실행 시간을 확인합니다.
